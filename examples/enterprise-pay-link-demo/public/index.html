Merchant Checkout Demo

Clicking “Pay” makes this demo create a parameter-locked Pay Link via the Enterprise API. The payer opens the link and pays with their own wallet on Givro (non-custodial, no auto-debit).

checking API key…

End-to-end steps

  1. Register / sign in to Enterprise at https://givro.to/enterprise and create a test API key.
  2. Put the key in GIVRO_API_KEY in this directory’s .env, then npm start.
  3. Adjust the amount / recipient email on this page and click “Pay” → a pay_url is created.
  4. Open the link to Givro /send, approve with your wallet, and complete funding.
